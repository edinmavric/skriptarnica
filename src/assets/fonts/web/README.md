# Web fonts

`piazzolla-sr.woff2` and `golos-sr.woff2` are variable fonts built from the Google Fonts
sources (`ofl/piazzolla/Piazzolla[opsz,wght].ttf`, `ofl/golostext/GolosText[wght].ttf`) with
fontTools: Piazzolla pinned to opsz=30 and limited to wght 600–800, Golos to wght 400–700, then
subset to U+0020-007E, U+00A0-00FF, č ć đ š ž (upper and lower case), dashes, quotes, bullet,
ellipsis, per mille, guillemets, €, №, ™, arrows, minus and ≤/≥. Licence: SIL Open Font License
1.1 (texts alongside); neither family declares a Reserved Font Name.
