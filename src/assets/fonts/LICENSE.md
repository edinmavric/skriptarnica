# Fonts used for generated Open Graph images

- Piazzolla 700 (Huerta Tipográfica), SIL Open Font License 1.1
- Golos Text 400/600 (Paratype), SIL Open Font License 1.1

TrueType files from Google Fonts (satori needs TTF/OTF, not WOFF2), subset to Latin, Latin
Extended and Cyrillic with fontTools; GSUB removed (satori can't read its contextual lookups),
kerning kept. The website itself loads
the same families through next/font.
